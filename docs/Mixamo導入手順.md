# Mixamo キャラクター導入手順

現在のキャラクターは Blender の Skin モディファイアで作った顔の無い人型で、
様式としては成立しているが写実には届かない。皮膚・髪・衣服のしわは手続き生成の
限界の外にある。Mixamo はそこを埋められる唯一の無料手段。

**Adobe アカウントでのログインが必要なため、取得はユーザー側で行う必要がある。**
組み込み側（Unity へのインポート、Animator の設定、既存の敵/NPC への差し替え）は
自動化できるので、ファイルを置いてもらえれば以降は引き継げる。

## ライセンス

無料・ロイヤリティ不要・商用利用可。**再配布のみ禁止**。
ゲームに組み込んで出荷するのは可。生の FBX をアセットパックとして配布するのは不可。
今回の用途では問題ない。

## 手順

### 1. サインイン

<https://www.mixamo.com> にアクセスし、無料の Adobe アカウントでサインインする。

### 2. キャラクターを選ぶ（Characters タブ）

この作品に合うのは以下。いずれも既にリグ済み。

| 用途 | 候補 | 備考 |
|------|------|------|
| 夜間警備員 | `Ch24_nonPBR` / `Security Guard` 系 | 制服・体格がある人物 |
| 看護師・医師 | `Ch22_nonPBR` など白衣系、または一般人 | 白い服の人物 |
| 患者（主人公が見る対象） | 一般の男性/女性 | 病衣は無いので、白系の服の人物を選ぶ |
| 黒い人影 | 上のいずれか | Unity 側で黒いマテリアルに差し替えて使う |

**注意**: Mixamo のキャラクターは `nonPBR` と PBR 版がある。PBR 版を選ぶこと
（URP で正しく陰影が出る）。

### 3. アニメーションを選ぶ（Animations タブ）

キャラクターを選んだ状態でアニメーションを検索し、必要なものを取る。
最低限これだけあれば成立する。

- `Idle` — 待機。棒立ちを避けるため、わずかに揺れるものを選ぶ
- `Walking` — 通常歩行。NPC 用
- `Walking` の遅いもの、または `Zombie Walk` — 敵の巡回用。異様さが出る
- `Running` — 敵の追跡用
- `Standing Idle` / `Looking Around` — 立ち止まって周囲を見る動き

### 4. ダウンロード設定

Download ボタンを押すと形式を選べる。**以下で固定する。**

| 項目 | 設定 | 理由 |
|------|------|------|
| Format | **FBX Binary (.fbx)** | Unity が直接読める |
| Skin | 最初の1体は **With Skin**、以降のアニメーションは **Without Skin** | メッシュを重複させない |
| Frames per Second | 30 | 十分 |
| Keyframe Reduction | none | 動きの質を落とさない |

「With Skin」でキャラクター本体を1つ落とし、同じキャラクターの他のアニメーションは
「Without Skin」で落とす。こうすると Unity 側でアニメーションだけを差し替えられる。

### 5. 配置

落とした FBX を以下に置く。フォルダは作ってある。

```
Assets/Models/Mixamo/
  Guard/       … 夜間警備員（With Skin 1体 + Without Skin のアニメーション）
  Civilian/    … 看護師・医師・患者に使う一般人
  Animations/  … 複数キャラで共有するアニメーション
```

置いたら「Mixamo のファイルを置いた」と伝えてもらえれば、以降を引き継ぐ。

## こちらで行う組み込み作業

1. FBX のインポート設定（Rig を Humanoid、Avatar の自動生成、Material の Import 設定）
2. Animator Controller の作成（Idle / Walk / Run の状態遷移、速度による切り替え）
3. `EnemyController` / `NPCManager` から Animator を駆動する処理の追加
   （現在は NavMeshAgent が滑るように動くだけでモーションが無い）
4. 既存の `Visual` / `Visual_Shadow` を Mixamo のモデルに差し替え
5. 黒い人影は同じモデルに `Char_ShadowFigure` を適用し、縦に引き伸ばして使う
6. ライトマップの焼き直しとプレイテスト

## 期待できる効果

現状、敵は NavMesh 上を**滑るように移動している**。歩行モーションが付くだけで
挙動の説得力が大きく変わる。加えて写実的な人体になることで、背景と人物の
落差（現在の最大の弱点）が解消する。
